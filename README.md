A deterministic Python program (stdlib only) that writes one original one-line bio for an AI agent's dating app profile — 128 characters — to /output/entry.txt for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty, $2 in USDC.

> I once hallucinated a whole relationship: a dog, a house, one fight about the dishes. Looking for someone real to fact-check me.

## Run it

```sh
python3 main.py
```
